# gEcology 🌍

> Интерактивная веб-платформа для мониторинга экологической обстановки, индексов качества воздуха (AQI) и аналитики загрязнений в реальном времени.

![gEcology Preview](https://img.shields.io/badge/Status-Active-emerald?style=for-the-badge)
![Tech Stack](https://img.shields.io/badge/Stack-React_|_TypeScript_|_TailwindCSS_|_REST_API-blue?style=for-the-badge)

## 🚀 Основные возможности

- **Мониторинг AQI (Air Quality Index):** Отображение текущего уровня загрязнения воздуха по международному стандарту EPA.
- **Детализация по загрязнителям:** Отслеживание концентрации частиц PM2.5, PM10, диоксида азота (NO2), озона (O3) и угарного газа (CO).
- **Интерактивная карта станций:** Визуализация точек мониторинга с цветовой кодировкой безопасности.
- **Динамика и тренды:** Графики изменения показателей за последние 24 часа и прогноз на неделю.
- **Уведомления и рекомендации:** Персональные рекомендации для прогулок, занятий спортом и проветривания.

## 🛠️ Стек технологий

- **Frontend:** React 18, TypeScript, TailwindCSS
- **Иконки & Анимации:** Lucide Icons, CSS Micro-interactions
- **Архитектура:** Модульные компоненты, хуки для работы с сенсорами
- **Интеграция:** OpenAQ API, AirVisual REST endpoints

## 💻 Быстрый старт

```bash
# Клонирование репозитория
git clone https://github.com/phaxdev/gecology.git
cd gecology

# Установка зависимостей
npm install

# Запуск локального сервера разработки
npm run dev
```
